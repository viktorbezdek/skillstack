## [1.0.0] - 2026-05-20

### Added

- Initial release with 5 hardened principles based on empirical SE literature
- Principle 1: Think Before Coding — clarification thresholds, spec/model/code uncertainty split, question budget
- Principle 2: Simplicity First — production calibration, Metz's duplication rule, deep-module discipline
- Principle 3: Surgical Changes — scope declaration contract, test-gaming firewall, phantom change prevention
- Principle 4: Goal-Driven Execution — adversarial test discipline, iteration budget, structured stopping rules
- Principle 5: Calibrated Communication — DONE/VERIFIED schema, ego-signaling suppression, partial-completion protocol
- Full references/principles.md with per-principle critiques, empirical backing, and conflict resolution
- Trigger evals covering positive activation, near-miss negatives, and principle-name variants
- Output evals for Boy Scout trap diagnosis, goal-driven execution, and completion schema usage
